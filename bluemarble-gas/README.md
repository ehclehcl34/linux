# 🎲 부루마블 (Google Apps Script 웹앱)

Google Apps Script 웹앱으로 만든 부루마블입니다. 2~4명이 할 수 있고, 빈자리는 컴퓨터로 채울 수 있습니다.

- **🖥️ 한 PC에서 같이**: 한 화면에서 번갈아 가며 플레이
- **🌐 각자 PC에서 (온라인)**: 방을 만들고 코드를 공유해서 각자 기기로 플레이

## 설치 방법

1. <https://script.google.com> 에서 **새 프로젝트**를 만듭니다.
2. 기본 `Code.gs` 내용을 이 폴더의 `Code.gs`로 바꿉니다.
3. **파일 ＋ → HTML** 로 `Index` 파일을 만들고 `Index.html` 내용을 붙여 넣습니다.
4. (선택) **프로젝트 설정 → "appsscript.json" 매니페스트 파일 표시**를 켜고 `appsscript.json` 내용을 붙여 넣습니다.
5. **배포 → 새 배포 → 유형: 웹 앱**
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자**
6. 나온 웹 앱 URL로 접속하면 게임이 시작됩니다.

> 브라우저에서 `Index.html`을 바로 열어도 플레이할 수 있습니다. 이때는 저장이 서버 대신 브라우저의 localStorage에 됩니다.

## 온라인으로 하기

1. 방장이 **🌐 각자 PC에서** 탭에서 이름을 쓰고 **방 만들기**를 누릅니다.
2. 화면에 나온 **방 코드(5자리)** 나 **링크**를 친구에게 보냅니다.
3. 친구들은 같은 웹앱 주소로 들어와서 이름과 방 코드를 넣고 **참가하기**를 누릅니다.
4. 방장이 필요하면 **🤖 컴퓨터 추가**를 하고 **게임 시작**을 누릅니다.

- 자기 차례일 때만 버튼이 나오고, 다른 사람의 주사위, 말 이동, 황금열쇠는 1~2초 안에 모두의 화면에 보입니다.
- 새로고침하면 같은 방으로 자동으로 돌아옵니다. 창을 닫았다면 **같은 이름**으로 다시 참가하면 원래 자리로 돌아갑니다.
- 누가 자리를 오래 비우면 방장 화면에 **🤖 컴퓨터가 대신하기** 버튼이 생깁니다. 그 사람이 다시 들어오면 자리를 돌려받습니다.
- 컴퓨터 플레이어는 방장 브라우저에서 움직이므로, 방장은 게임이 끝날 때까지 창을 열어 두세요.
- 웹앱 배포 설정이 **액세스: 모든 사용자**여야 친구들이 들어올 수 있습니다. 코드를 바꿨다면 **배포 관리 → 수정 → 새 버전**으로 다시 배포하세요.

## 저장 / 이어하기 (한 PC 모드)

- 매 턴이 끝날 때 자동 저장되며 **저장 코드**(6자리)가 오른쪽 패널에 표시됩니다.
- 같은 기기에서는 시작 화면의 **▶ 이어하기**로, 다른 기기에서는 저장 코드를 입력해서 이어서 할 수 있습니다.
- 서버에는 스크립트 속성(`PropertiesService`)에 최근 50개 게임까지 보관합니다.

## 팁

- 칸을 누르면 가운데에 땅값, 단계별 통행료, 소유자가 표시됩니다.
- 스페이스바로 주사위를 굴릴 수 있습니다.
- 금액과 규칙 수치는 `Index.html` 위쪽의 `설정` 부분 상수(`START_MONEY`, `SALARY`, `RENT_MUL` 등)에서 바꿀 수 있습니다.

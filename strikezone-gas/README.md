# 🎯 STRIKE ZONE (Google Apps Script 웹앱)

발로란트 느낌의 5 vs 5 전술 FPS입니다. 브라우저에서 3D(three.js)로 돌아가고, 혼자(봇 대전) 또는 친구들과 온라인으로 할 수 있습니다. PC는 키보드+마우스, 휴대폰/태블릿은 배그 모바일처럼 조이스틱과 터치 버튼으로 조작합니다.

## 설치 방법

1. <https://script.google.com> 에서 **새 프로젝트**를 만듭니다. (부루마블과 다른 프로젝트로 만드세요)
2. 기본 `Code.gs` 내용을 이 폴더의 `Code.gs`로 바꿉니다.
3. **파일 ＋ → HTML** 로 `Index` 파일을 만들고 `Index.html` 내용을 붙여 넣습니다.
4. **배포 → 새 배포 → 유형: 웹 앱** / 실행 사용자: **나** / 액세스 권한: **모든 사용자**
5. 나온 `/exec` 주소로 접속합니다. (주소에 `/u/1/`이 있으면 지우세요)
6. PC라면 메인 메뉴의 **🖥️ 새 창으로 열기**를 누르세요. 구글 웹앱 화면 안에서는 브라우저 보안 때문에 마우스 고정(포인터 락)이 막혀 있어서, 새 창에서 해야 FPS처럼 마우스가 고정됩니다. (온라인을 할 땐 원래 창을 닫지 마세요)

## 게임 방법

- **공격팀**: 스파이크를 A 또는 B 사이트에 설치하고 45초 동안 지키면 승리
- **수비팀**: 설치를 막거나, 설치된 스파이크를 해체(7초, 절반 지나면 저장)하면 승리
- 상대 팀을 전멸시켜도 라운드 승리 (단, 설치 후에는 수비팀만 전멸 조건 적용)
- 라운드 시작 20초는 **구매 시간** — 스폰 구역 밖으로 못 나가고, 크레딧으로 무기·방어구·스킬을 삽니다
- 승리 3000 / 패배 1900(+연패 보너스) / 처치 200 / 설치 300 크레딧
- 정해진 승수(3/5/7/13)의 절반 지점에서 공수 교대

## 온라인

1. 방장이 **🌐 온라인 → 방 만들기** → 5자리 방 코드를 친구에게 알려 줍니다.
2. 친구는 같은 웹앱 주소에서 **방 코드 입력 → 참가**.
3. 로비에서 팀과 요원을 고르고, 방장이 팀 인원·봇 난이도·승리 조건을 정해 **매치 시작** (빈자리는 봇).

- 방장 PC가 게임 서버 역할을 하고, 플레이어끼리 **직접 연결(WebRTC)** 하므로 지연이 작습니다. 구글 서버는 처음 연결할 때만 중개합니다.
- 회사/학교처럼 방화벽이 강한 네트워크나 일부 모바일 데이터에서는 직접 연결이 안 될 수 있습니다. 그럴 땐 다른 와이파이로 시도하세요.
- 게임 중 누가 나가면 그 자리는 봇이 이어받습니다. 방장이 나가면 게임이 끝납니다.
